# Fuel Station Finder ⛽

Fuel Station Finder is a web application that helps drivers find fuel stations and view available fuel price information.

## Features

- 🔍 Search for fuel stations by name or location
- ⛽ Filter stations by fuel type
- 📍 View fuel station locations
- 💰 View reported fuel prices
- 📊 Display the total number of available stations
- 📱 Responsive and easy-to-use interface

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## How to Use

1. Open the Fuel Station Finder website.
2. Search for a station or location using the search bar.
3. Use the fuel type dropdown to filter stations.
4. View the available stations and their fuel information.
5. Use the report feature to report a fuel price.
